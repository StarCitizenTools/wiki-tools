# Template:PledgeVehicleGrid

Renders the pledge vehicle list as a sortable, filterable AG Grid data table. Place it once, on [List of pledge vehicles](https://starcitizen.tools/List_of_pledge_vehicles).

## Usage

```wikitext
{{PledgeVehicleGrid}}
```
