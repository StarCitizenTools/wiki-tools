# pages

A mirror of the [Star Citizen Wiki](https://starcitizen.tools), one directory per namespace.

| Directory | Namespace | Contents |
|---|---|---|
| `module/` | `Module:` | Scribunto modules (`.lua`) with their TemplateStyles (`.css`), JSON data, and `testcases.lua` suites. |
| `template/` | `Template:` | Templates (`.wikitext`) and their TemplateStyles. |
| `mediawiki/` | `MediaWiki:` | Gadgets and the gadget registry. See [`mediawiki/README.md`](mediawiki/README.md). |

A page's path is its title: `module/Entity/Entity.lua` is `Module:Entity`, `module/Entity/Base.lua` is `Module:Entity/Base`, `template/Badge/Badge.wikitext` is `Template:Badge`, and `module/Rarity/styles.css` is `Module:Rarity/styles.css`. A page with subpages lives in its own directory next to them, and the file extension sets the content model. `AGENTS.md` at the repository root has the full rules and the conventions for editing modules.

The `README.md` beside a page is the source of its live `/doc` page: `module/Entity/README.md` becomes `Module:Entity/doc`, converted on deploy. Every top-level module and template directory has one, and the catalog below is generated from them by `mise run docindex` (title from the H1, summary from the first sentence); `mise run lint` fails while it is stale.
